AI-Based Emotional Wellness & Stress Predictor (SereneAI)

About the Project

SereneAI is an AI-based wellness website designed to help users understand their daily mood and stress levels.

Features

- Daily mood tracking
- Sleep and workload tracking
- Stress-level estimation: Low, Moderate, High
- Personalized wellness suggestions
- Interactive dashboard and reports

Technologies Used

- React
- TypeScript
- Gemini AI

Purpose

To encourage emotional awareness and healthy daily habits through AI-assisted analysis.

Disclaimer

This project is for general wellness awareness only. It is not a medical diagnosis or substitute for professional support.
